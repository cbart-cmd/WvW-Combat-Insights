# Security policy

Only the current released version is maintained. Reproduce reports on the
current version when possible; do not test on other people's systems or data.

Do not disclose suspected vulnerabilities, exploit details, credentials or
private logs in public issues.

Use GitHub's private
[Report a vulnerability](https://github.com/cbart-cmd/WvW-Combat-Insights/security/advisories/new)
form. Include the affected version, impact, reproduction steps and a minimal
synthetic sample if available. Do not attach real player data.

Updates and advisories are provided on a best-effort basis, without a guaranteed
response time. This project is not affiliated with ArenaNet, Nexus or arcdps.
